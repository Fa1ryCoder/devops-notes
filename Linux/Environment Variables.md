Что такое переменные окружения в Linux

В Linux переменные окружения — это именованные значения (пары «ключ=значение»), которые хранят настройки и параметры работы процессов в операционной системе. Проще говоря, это способ передать программам/скриптам настройки и параметры через систему, а не через код или файлы конфигурации. Главная идея переменных окружения — гибкая настройка поведения программ.
Во-первых, они используются для системной конфигурации. Например, переменная PATH говорит оболочке, в каких каталогах искать исполняемые файлы. Когда вы вводите команду ls, система ищет её в каталогах, перечисленных в PATH. Переменная HOME указывает домашний каталог пользователя, а USER содержит имя текущего пользователя.
Во-вторых, переменные окружения широко используются для настройки приложений. Вместо того чтобы прописывать параметры в коде, программа может читать их из окружения. Например, веб-сервер может получать номер порта из переменной PORT, а база данных — пароль из DB_PASSWORD. Это особенно важно в контейнерах, CI/CD и серверных приложениях.
В-третьих, переменные окружения удобны для хранения секретов. Пароли и токены не стоит хранить в коде или репозитории. Их задают через окружение, чтобы отделить конфигурацию от программы. Чтобы увидеть все переменные окружения в текущей сессии, используется команда:
- env

Если нужно посмотреть конкретную переменную, можно написать:
- echo $PATH

Установка переменных окружения в Linux
Чтобы создать новую переменную оболочки с именем NEW_VARIABLE и значением "test", и затем сразу экспортировать ее введите:
- export NEW_VARIABLE='test'

И проверяем:
- echo $NEW_VARIABLE

Используя export, ваша переменная окружения будет установлена для текущего сеанса оболочки. Как следствие, если вы откроете другую оболочку или перезапустите свою систему, переменная окружения больше не будет доступна.

Установить постоянные переменные окружения в Linux --> Использование файла .bashrc
Самый популярный способ постоянной установки переменных среды - это добавить их в файл .bashrc. Файл .bashrc - это скрипт, выполняемый всякий раз, когда вы инициализируете сеанс интерактивной оболочки.
