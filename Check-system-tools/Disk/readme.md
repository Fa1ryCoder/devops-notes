df - disk free. df показывает использование дискового пространства на уровне файловых систем (разделов). Предназначение: Свободное место на разделах + иноды. df показывает данные на момент снятия статистики, но если файл был удален (rm), а процесс продолжает держать его открытым, df всё ещё будет показывать это место как занятое. В такой ситуации помогает lsof | grep deleted.

du - disk usage. disk usage (использование места в каталогах). du анализирует файлы и директории, показывая, сколько места занимает каждый объект. Предназначение: Поиск "жирных" папок, точечная чистка.

lsblk — list block devices. lsblk — это утилита для отображения информации о блочных устройствах (дисках, разделах, LVM томах, RAID-массивах) в древовидном виде. Она показывает, как диски физически подключены и как они логически организованы.

ps aux | awk '$8 ~ /D/ {print}' - Эта команда используется для поиска процессов, которые находятся в «глубоком сне» и блокируют работу системы. 
awk '$8 ~ /D/ {print}'
Это фильтр, который обрабатывает таблицу данных от ps:

$8 — смотреть только в 8-ю колонку вывода. В формате ps aux восьмая колонка — это STAT (состояние процесса).

~ /D/ — искать строки, где в этой колонке встречается буква D.

{print} — если условие совпало (найдена буква D), вывести всю строку на экран.
