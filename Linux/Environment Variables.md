Что такое переменные окружения в Linux

В Linux переменные окружения — это именованные значения (пары «ключ=значение»), которые хранят настройки и параметры работы процессов в операционной системе. Проще говоря, это способ передать программам/скриптам настройки и параметры через систему, а не через код или файлы конфигурации. Главная идея переменных окружения — гибкая настройка поведения программ.
1) Они используются для системной конфигурации. Например, переменная PATH говорит оболочке, в каких каталогах искать исполняемые файлы. Когда вы вводите команду ls, система ищет её в каталогах, перечисленных в PATH. Переменная HOME указывает домашний каталог пользователя, а USER содержит имя текущего пользователя.
2) Переменные окружения широко используются для настройки приложений. Вместо того чтобы прописывать параметры в коде, программа может читать их из окружения. Например, веб-сервер может получать номер порта из переменной PORT, а база данных — пароль из DB_PASSWORD. Это особенно важно в контейнерах, CI/CD и серверных приложениях.
3) Переменные окружения удобны для хранения секретов. Пароли и токены не стоит хранить в коде или репозитории. Их задают через окружение, чтобы отделить конфигурацию от программы. 
Чтобы увидеть все переменные окружения в текущей сессии, используется команда:
- env

Если нужно посмотреть конкретную переменную, можно написать:
- echo $PATH

Чтобы создать новую переменную оболочки с именем NEW_VARIABLE и значением "test", и затем сразу экспортировать ее введите:
- export NEW_VARIABLE='test'

И проверяем:
- echo $NEW_VARIABLE

Используя export, ваша переменная окружения будет установлена для текущего сеанса оболочки. Как следствие, если вы откроете другую оболочку или перезапустите свою систему, переменная окружения больше не будет доступна.

Установить постоянные переменные окружения в Linux для ТЕКУЩЕГО пользователя --> Использование файла .bashrc
Самый популярный способ постоянной установки переменных среды - это добавить их в файл .bashrc. Файл .bashrc - это конфигурационный скрипт оболочки Bash, который автоматически выполняется каждый раз, когда вы открываете новое окно терминала или запускаете новый интерактивный сеанс командной строки. Чаще всего его используют для:
1) Создания алиасов (Aliases): Сокращений для длинных команд. Например, чтобы вместо git checkout писать просто gco.
2) Настройки PATH: Указания системе, в каких папках искать исполняемые программы.
3) Изменения внешнего вида (PS1): Настройки цвета текста, отображения текущей папки, времени или ветки Git в строке приглашения.
4) Экспорта переменных окружения: Например, настройки часового пояса или выбора редактора по умолчанию (EDITOR=nano).
Важно: если внести изменения в .bashrc, то они не применятся в текущем окне терминала мгновенно. Что бы применить настройки, необходимо перезапустить терминал или выполнить комманду source ~/.bashrc 

Если необходимо установить переменную окружения глобальную т.е для всех пользователей сразу, то необходимо перейти в файл /etc/environment и так же экспортировать нужную переменную:
- export NEW_VARIABLE='test'

Не забываем перечитать файл с помощью source /etc/environment.
